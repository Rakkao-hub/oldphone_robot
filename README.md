# แซน : หุ่นยนต์รถที่มีมือถือ Android เป็นสมอง

รถ 2 ล้อ (ESP8266 + L298N) ที่มีมือถือวางอยู่บนตัว มือถือทำหน้าที่เป็นหน้าตา หู ตา และสมอง

- 🗣️ สั่งด้วยเสียงภาษาไทย: "เดินหน้า 50 เซนติเมตร", "เลี้ยวซ้าย", "วิ่งเป็นรูปหัวใจ", "เต้นหน่อย", "หยุด"
- 😊 หน้าตาบนจอ: ตากะพริบ มองไปมา มีอารมณ์ ปากขยับตามเสียงพูด เรียก "แซน" แล้วยิ้ม
- 👀 มองตามหน้าคนด้วยกล้องหน้า (MediaPipe) และ "แซน ตามมา" ให้รถหมุนหันหน้าตามคน
- ⚡ ไม่มีคุยเล่น: เข้าใจเฉพาะคำสั่งขยับ ตอบทันที มือถือทำงานเบา (ถ้าเรียก "แซน" แล้วพูดเรื่องอื่น จะบอกว่าทำอะไรได้บ้าง)
- 🌐 หน้าเว็บบนบอร์ดยังสั่งรถได้เหมือนเดิม (http://robot.local)
- 👏 ชมหรือดุได้: "เก่งมาก" แซนดีใจ, "ดื้อจัง" แซนขอโทษ, "ไม่เอา เลี้ยวซ้าย" = แก้คำสั่ง, ถาม "ได้คำชมกี่ครั้ง" ได้ แซนจำข้ามวัน ท่าที่ถูกชมบ่อยแซนจะบอกว่าถนัด ท่าที่โดนดุบ่อยแซนจะบอกว่าจะระวัง (ความจำจางลงครึ่งทุก 7 วัน)
- 🔎 ภารกิจหาของ: "จำของ หมี" แล้วถือหมีให้แซนดู → "หาหมี" แซนหมุนมองรอบตัว เดินไปหาที่อื่น เจอแล้วเข้าไปใกล้และประกาศว่าเจอ
- 👋 จำหน้าคน: เจอคนใหม่ถาม "ชื่ออะไรเหรอ" จำหน้าคู่กับชื่อ ครั้งหน้าเห็นก็ทัก "สวัสดีต้น"
- 🤔 โหมดสงสัย: เจอของที่ไม่เคยเห็น แซนไปดู จดจำ ถ่ายรูปไว้ เห็นคนแล้วโชว์รูปถาม "อันนี้คืออะไรเหรอ" ตอบชื่อแล้วสั่งหาได้เลย
- 🔋 สัญชาตญาณจากแบต: แบตเยอะคึก สำรวจแทบตลอด แบตน้อยขี้เกียจ แบตต่ำทำหน้าเหนื่อย ใกล้หมดอ้อนขอชาร์จ
- 🪰 สัญชาตญาณ: ตอนว่าง ตาจะเหลือบตามสิ่งที่ขยับ และถ้าขยับชัด ๆ แซนจะหันตัวไปดู สนใจของที่ไม่เคยเห็น สะดุ้งถอยเมื่อมีอะไรพุ่งเข้าหา และเบื่อแล้วออกเดินสำรวจเอง โดยใช้ผังสายไฟจริงของสมองแมลงวันผลไม้ 500 เซลล์ (อารมณ์ดี = มองหา, ถูกดุจนงอน = มองหนี)

```
Chrome เต็มจอ (face.html)  ──localhost──>  Termux: brain.py  ──WiFi HTTP──>  ESP8266 ──> L298N ──> ล้อ
  หน้าตา / ฟัง / พูด / กล้อง                   สมอง (แปลงคำพูดเป็นคำสั่งรถ)
```

## โครงสร้าง

| ไฟล์ | ทำอะไร |
|---|---|
| `phone/brain.py` | สมอง: รับคำที่ได้ยิน → สั่งรถ, โหมดตามหน้า, เสียงพูด (Python ล้วน มีแค่ edge-tts ที่ติดตั้งเพิ่มได้) |
| `phone/commands.py` | แปลงคำพูดไทยเป็นคำสั่งรถ `F<ซม.> B<ซม.> L<องศา> R<องศา>` และเส้นทางรูปทรง |
| `phone/face.html` | หน้าตาแซนใน Chrome: วาดตา ฟังเสียง เล่นเสียงพูด กล้องจับหน้า |
| `phone/feedback.py` | คำชม/ตำหนิ: จับคำ อารมณ์สะสมที่ค่อย ๆ จาง และสมุดจด `.feedback.json` |
| `phone/people.py` | จำหน้าคน: หน้าที่รู้จัก `.people.json` รอคำตอบชื่อ "ผมชื่อ..." |
| `phone/mission.py` | ภารกิจหาของ/เดินสำรวจ: แยกคำสั่งเสียง สมุดของที่จำไว้ `.items.json` และตัดสินว่ายอมให้ขยับล้อไหม |
| `phone/fly/` | สัญชาตญาณ: `fly_brain.js` (สมองแมลงวันจิ๋ว) `instinct.js` (กล้อง → สมอง → ตา/ล้อ) `curiosity.js` (จำภาพที่เคยเห็น) `explore.js` (เดินสำรวจ) `wonder.js` (โหมดสงสัย) `energy.js` (นิสัยตามแบต) `people.js` (จำหน้าคน) `mission.js` (สอนจำของ + ออกตามหา) `motion.js` (ขยับทีละท่า + จับว่าชน) `dnp20.json` (ผังสายไฟ) |
| `phone/start.sh` | เปิดทุกอย่างด้วยคำสั่งเดียว |
| `phone/get_vendor.sh` | โหลด MediaPipe มาเก็บในเครื่อง |
| `firmware/robot_ai/` | เฟิร์มแวร์ NodeMCU: คุมมอเตอร์ WiFi และหน้าเว็บสั่งรถ |

## ติดตั้ง

### บอร์ด (NodeMCU 1.0 / ESP-12E)
1. คัดลอก `firmware/robot_ai/secrets.example.h` เป็น `secrets.h` แล้วใส่ชื่อ/รหัส WiFi (2.4 GHz เท่านั้น)
   - ใส่ WiFi สำรองได้อีกชื่อ (`WIFI2_SSID` / `WIFI2_PASS`) บอร์ดจะต่อตัวที่สัญญาณแรงกว่า ต่อไม่ติดก็ลองอีกตัว ถ้าไม่เจอทั้งคู่จะต่อ Hotspot มือถือ (`PHONE_SSID`) และถ้ายังไม่ได้อีกจะเปิด WiFi "Robot-AI" เอง
   - ESP8266 ใช้ 5 GHz ไม่ได้ แต่มือถือใช้ 5 GHz ของเราเตอร์ตัวเดียวกันได้ (ห้ามเป็น WiFi แขก)
2. อัปโหลดด้วย Arduino IDE หรือ `arduino-cli upload -p <พอร์ต> --fqbn esp8266:esp8266:nodemcuv2 firmware/robot_ai`

### มือถือ (Termux)
```
pkg install python
MULTIDICT_NO_EXTENSIONS=1 YARL_NO_EXTENSIONS=1 FROZENLIST_NO_EXTENSIONS=1 PROPCACHE_NO_EXTENSIONS=1 AIOHTTP_NO_EXTENSIONS=1 pip install edge-tts
bash phone/get_vendor.sh
bash phone/start.sh
```
แล้วแตะหน้าจอใน Chrome เพื่อปลุกแซน อนุญาตไมค์และกล้อง

## ข้อควรรู้
- การฟังเสียงของ Chrome และเสียงพูดต้องใช้อินเทอร์เน็ต เสียงพูดใช้เสียง AI ภาษาไทยของ Microsoft Edge (`edge-tts`) ถ้าไม่ได้ติดตั้งหรือใช้ไม่ได้จะใช้ Google Translate TTS แทน
- เปลี่ยนเสียง (ผู้ชาย/ผู้หญิง ความเร็ว เสียงสูงต่ำ) ได้ที่ `TTS_VOICE` `TTS_RATE` `TTS_PITCH` ใน `phone/start.sh`
- หน้าเว็บและ API ของบอร์ดไม่มีรหัสผ่าน ใครอยู่ใน WiFi เดียวกันสั่งรถได้ ใช้ในเครือข่ายที่ไว้ใจเท่านั้น
- `brain.py` รับคำสั่งควบคุมเฉพาะจากในมือถือเอง (localhost)
- แตะหน้าจอ = รถหยุดทันที

## ภารกิจหาของ
1. **สอนก่อน**: พูด "จำของ หมี" (หรือ "นี่คือหมี", "จำหมีไว้") แล้วถือหมีให้กล้องหน้าดูใกล้ ๆ หมุนให้ดูหลายด้านราว 8 วินาที มุมจอจะโชว์ภาพกล้องและเปอร์เซ็นต์ แซนจำได้ข้ามวัน (ไฟล์ `phone/.items.json`) ถ้าแซนบอกว่า "ภาพยังคล้ายฉากรอบ ๆ" ให้สอนใหม่โดยถือให้ใกล้กว่าเดิม ให้ของเต็มกลางภาพ
2. **สั่งหา**: "หาหมี" / "ไปหาหมี" / "ภารกิจหาหมี" ชื่อไม่ต้องตรงเป๊ะ ("ตุ๊กตาหมี" ก็หา "หมี" ได้) ถ้ายังไม่เคยสอน แซนจะบอกให้สอนก่อน
   - ไม่เห็น: หมุนทีละ 30 องศาจนครบรอบ แล้วเดินไปที่ใหม่ 30 ซม. หมุนหาอีก
   - เห็น: หันให้ของอยู่กลางภาพ เดินเข้าไปทีละ 10-20 ซม. จนของเต็มกลางภาพ (หรือชนของ) ดีใจ พูด "เจอหมีแล้ว"
   - หาไม่เจอใน 3 นาที (หรือ 60 ท่า) แซนบอกว่าหาไม่เจอ
   - มุมจอโชว์ภาพกล้องกับกรอบที่แซนคิดว่าใช่ที่สุด (เขียว = ใช่, เทา = ยังไม่ใช่)
3. หยุดได้ทุกเมื่อ: พูด "หยุด" คำสั่งอื่น หรือแตะจอ
- "รู้จักของอะไรบ้าง" = บอกรายชื่อ, "ลืมหมี" = ลบ (จำได้สูงสุด 30 ชิ้น)
- ต้องมีโมเดลจำของ `phone/vendor/embedder.tflite` (`deploy.sh` โหลดให้เองครั้งแรก หรือรัน `bash phone/get_vendor.sh` บนมือถือ)
- รถไม่มีเซนเซอร์วัดระยะ จึงรู้ว่า "ชน" จากภาพ (สั่งเดินหน้าแล้วภาพแทบไม่เปลี่ยน) แล้วถอยหลังหันไปทางอื่น ใช้บนพื้นเท่านั้น ห้ามใช้บนโต๊ะ
- ของที่หน้าตาคล้ายกันอาจสับสนกันได้ ผลแต่ละภารกิจ (ความคล้ายสูงสุดเทียบเกณฑ์) เขียนไว้ใน `brain.log`

## จำหน้าคน
- เห็นหน้าคนที่ไม่รู้จัก (ใกล้พอ ราว 1 เมตร) -> "สวัสดี แซนยังไม่รู้จักเลย ชื่ออะไรเหรอ" ตอบ "ต้น" / "ผมชื่อต้น" -> "ยินดีที่ได้รู้จักนะ ต้น" (ถามคนแปลกหน้าไม่เกินทุก 3 นาที ตอบ "ไม่บอก" ได้)
- เห็นคนที่รู้จัก -> "สวัสดีต้น" / "อ้าว ต้น มาแล้ว" (ทักคนเดิมไม่เกินทุก 10 นาที)
- พูด "ผมชื่อต้น" / "หนูชื่อมิว" ตอนอยู่หน้าแซน -> จำหน้าตอนนั้นเลย (ใช้สอนเพิ่มตอนแซนจำไม่ได้ หรือแก้ตอนทักผิดชื่อ ยิ่งสอนหลายครั้งหลายแสงยิ่งแม่น)
- "แซนรู้จักใครบ้าง" / "ลืมหน้าต้น"
- ใช้ face-api (MIT) ใน Chrome ต้องมีโมเดลใน `phone/vendor/faceapi/` (`deploy.sh` โหลดให้ครั้งแรก ~8 MB)
- **ความเป็นส่วนตัว**: เก็บแค่ตัวเลขลายนิ้วมือหน้า (ไม่เก็บรูป) ในไฟล์ `.people.json` บนมือถือเท่านั้น ไม่ส่งออกเน็ต ไม่ขึ้น git เครื่องอื่นใน WiFi ขอดูไม่ได้ ลบทั้งหมดได้ด้วย `rm ~/robot/.people.json` ควรบอกคนที่มาเล่นด้วยว่าแซนจำหน้า
- ไม่แม่น 100%: แสงมืด ใส่แมส หันข้าง หรือพี่น้องหน้าคล้ายกันอาจทักผิด ถ้าทักผิดพูด "ผมชื่อ..." สอนใหม่ได้ ปรับความเข้มงวดได้ที่ `SAME` / `DIFFERENT` ใน `phone/fly/people.js`

## โหมดสงสัย
- ความอยากรู้เจอของใหม่ แซน "หืม นั่นอะไรน่ะ ขอดูหน่อย" หันไปดู 30 องศา จดลายนิ้วมือราว 3 วินาที และถ่ายรูปเล็ก ๆ เก็บไว้ (ไม่เกินทุก 2 นาที ค้างได้ 3 เรื่อง)
- เห็นหน้าคนเมื่อไร โชว์รูปกลางจอแล้วถาม "อันนี้คืออะไรเหรอ" (ไม่เกินทุก 1.5 นาที รอคำตอบ 1 นาที)
- ตอบ "แก้วน้ำ" / "มันคือแก้วน้ำ" -> "อ๋อ นี่คือแก้วน้ำนี่เอง" จำเป็นของชิ้นหนึ่ง สั่ง "หาแก้วน้ำ" ได้เลย (ตอบชื่อที่มีอยู่แล้ว = ได้เห็นของชิ้นนั้นเพิ่มอีกมุม)
- ตอบ "ไม่รู้" -> ทิ้งไป, สั่งรถระหว่างรอคำตอบได้ตามปกติ (คำสั่งไม่ถูกนับเป็นชื่อ), ถาม 3 ครั้งไม่มีใครตอบก็ลืม
- ข้อสงสัยเก็บไว้ในหน่วยความจำ เริ่ม brain.py ใหม่แล้วหายไป (ของที่ตอบชื่อแล้วอยู่ใน `.items.json` ถาวร)

## สัญชาตญาณจากแบต
ใช้แบตมือถือ (Chrome อ่านให้ แถบสถานะบนจอแสดง %) บอร์ดรถยังไม่มีวงจรวัดแบต 18650

| แบต | นิสัย |
|---|---|
| 40% ขึ้นไป | คึก: ไม่ง่วงเลย เบื่อหลัง 8 วิ สำรวจ 16 ก้าว พัก 15 วิ แล้วออกใหม่ |
| 30-40% | ปกติ: เบื่อหลัง 20 วิ สำรวจ 10 ก้าว พัก 1 นาที |
| 15-30% | ขี้เกียจ: เบื่อหลัง 1 นาที สำรวจแค่ 4 ก้าว พัก 3 นาที สั่งภารกิจแล้วบ่นว่าแบตน้อยแต่จะพยายาม |
| 8-15% | เหนื่อย: ไม่ออกสำรวจ ตาปรือ บ่นเหนื่อยทุก 4 นาที สั่ง "ไปสำรวจ" แล้วไม่ยอม |
| ต่ำกว่า 8% | ใกล้หมด: เลิกถามข้อสงสัย เห็นคนแล้วอ้อนขอชาร์จทุก 2 นาที |
| เสียบชาร์จ | ไม่ขยับล้อเองเลย (สายจะกระชาก) สั่งภารกิจ/สำรวจแล้วบอกให้ถอดสายก่อน เสียบตอนแบตต่ำจะขอบคุณ |

ปรับเส้นแบ่งและนิสัยได้ที่ `phone/fly/energy.js`

## สัญชาตญาณ (สมองแมลงวัน)
- ทำงานเฉพาะตอนแซนตื่น ว่าง และไม่เห็นหน้าใคร
- หันตัว: ถ้าของขยับอยู่ข้างเดียวชัด ๆ นานเกือบครึ่งวินาที แซนจะหมุนตัวไปทางนั้น 25-45 องศา (หมุนแล้วหยุดเอง) ได้อย่างมากทุก 6 วินาที (ถูกชมหลังหันบ่อย ๆ จะหันถี่ขึ้น โดนดุ 2 ครั้งขึ้นไปจะเลิกหันตัวจนกว่าความจำจางหรือถูกชมใหม่ ตายังเหลือบตามได้) จะไม่หันแทรกตอนรถกำลังทำท่า ตอนโหมดตามมา/พูดตาม หรือตอนคนเพิ่งสั่งรถไม่ถึง 5 วินาที ถ้าหันผิดทางให้ตั้ง `FOLLOW_FLIP=1` (ใช้ค่าเดียวกับโหมดตามหน้า) อยากให้แค่เหลือบตาไม่หมุนตัว ตั้ง `INSTINCT_TURN=0` ใน `phone/start.sh`
- ของที่ขยับซ้ำ ๆ ฝั่งเดิม (พัดลม ทีวี) แซนจะชินและเลิกมองเอง ภาพที่ขยับทั้งจอ (แซนหมุนตัว เปิดปิดไฟ) จะถูกมองข้าม
- ความอยากรู้: แซนจำภาพที่เคยเห็นไว้ใน Chrome (ข้ามวันได้ สูงสุด 400 ภาพ) เห็นของที่ไม่เหมือนภาพไหนเลย ตาจะโตอยากรู้ เหลือบหรือหันไปดู นาน ๆ ทีถามว่า "นั่นอะไรน่ะ" (อย่างมากทุก 5 นาที) ดูนิ่ง ๆ ครบ 3 วินาทีก็จำได้ ครั้งหน้าไม่ตื่นเต้นแล้ว วันแรกแซนจะสนใจไปทั่วเพราะยังไม่เคยเห็นอะไร ไฟสว่างขึ้นหรือมืดลงทั้งห้องไม่นับเป็นของใหม่
- สะดุ้งถอย: ของที่พุ่งตรงเข้าหากล้อง (บังภาพกว้างขึ้นเรื่อย ๆ จากกลางภาพจนเกินครึ่งในไม่ถึงครึ่งวินาที) แซนจะทำหน้าตกใจและถอยหลัง 10 ซม. ถ้าเพิ่งเห็นหน้าคน (คนโน้มเข้ามาคุย) จะแค่ทำหน้าตกใจ ไม่ถอย เปิดไฟพรึบหรือคนเดินผ่านจากขอบภาพจะไม่สะดุ้ง ปิดเฉพาะการถอยด้วย `INSTINCT_STARTLE=0`
- เดินสำรวจ: ตอนตื่นอยู่ ถ้าไม่มีใครคุยและไม่เห็นหน้าใครนานพอ (ขึ้นกับแบต) แซนจะ "เบื่อจัง ไปสำรวจดีกว่า" ก่อนแต่ละก้าวหยุดมอง 1.5 วินาที ให้สมองแมลงวันเลือกทิศ: ของที่ขยับหรือของใหม่ข้างไหนดึงดูดกว่า หันไปทางนั้นแล้วเดิน 15-25 ซม. ไม่มีอะไรกระตุ้นก็หันมองไปเรื่อย ๆ ทางเดิมครั้งละ 35-50 องศา หันมอง 3 ครั้งยังไม่เจออะไรค่อยเดินไปที่ใหม่ ชนแล้วถอยหันไปทางอื่น เห็นหน้าคนแล้วหยุด สั่งเองได้ด้วย "ไปสำรวจ" / "เลิกสำรวจ" ปิดการออกสำรวจเองด้วย `INSTINCT_EXPLORE=0` (แซนหลับหลังไม่มีใครคุย 2 นาที ตอนหลับไม่สำรวจ)
- ความจำใช้กับสัญชาตญาณด้วย: ถูกชมหลังหันตัวหรือสะดุ้งจะทำถี่ขึ้น โดนดุระหว่าง/หลังสำรวจ 2 ครั้งขึ้นไปจะเลิกออกสำรวจเอง โดนดุ 2 ครั้งขึ้นไปจะเลิกทำเรื่องนั้นเอง จนกว่าความจำจางหรือถูกชมใหม่
- ปิด/เปิดด้วยเสียง "ปิดสัญชาตญาณ" / "เปิดสัญชาตญาณ" หรือเริ่มแบบปิดด้วย `INSTINCT=0` ใน `phone/start.sh`
- ทุก 1 นาที `brain.log` จะมีบรรทัด "สัญชาตญาณ: สมองคำนวณเฉลี่ย ... ms ต่อรอบ" ไว้ดูว่ามือถือรับไหวไหม (หนึ่งรอบ = 100 ms) และบรรทัด "ความอยากรู้: ... ความต่าง a-b (เกิน 0.5 = ใหม่)" ถ้าแซนตื่นเต้นกับของเดิมบ่อยหรือไม่สนใจของใหม่เลย ให้ปรับ `NOVEL` ใน `phone/fly/curiosity.js`
- `dnp20.json` สร้างจากโปรเจกต์ fly_brain_test ด้วย `python 09_export_for_robot.py --to <ที่อยู่ไฟล์>` ผังสายไฟมาจากชุดข้อมูล MaleCNS ผ่าน neuPrint
- ผังสายไฟเป็นของจริง แต่พฤติกรรมของเซลล์เป็นแบบจำลองอย่างง่าย และการเลือกว่ากล้องไปกระตุ้นเซลล์ไหนเป็นการตัดสินใจของเรา
