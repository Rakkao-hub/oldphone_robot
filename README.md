# แซน : หุ่นยนต์รถที่มีมือถือ Android เป็นสมอง

รถ 2 ล้อ (ESP8266 + L298N) ที่มีมือถือวางอยู่บนตัว มือถือทำหน้าที่เป็นหน้าตา หู ตา และสมอง

- 🗣️ สั่งด้วยเสียงภาษาไทย: "เดินหน้า 50 เซนติเมตร", "เลี้ยวซ้าย", "วิ่งเป็นรูปหัวใจ", "เต้นหน่อย", "หยุด"
- 😊 หน้าตาบนจอ: ตากะพริบ มองไปมา มีอารมณ์ ปากขยับตามเสียงพูด เรียก "แซน" แล้วยิ้ม
- 👀 มองตามหน้าคนด้วยกล้องหน้า (MediaPipe) และ "แซน ตามมา" ให้รถวิ่งตาม
- ⚡ ไม่มีคุยเล่น: เข้าใจเฉพาะคำสั่งขยับ ตอบทันที มือถือทำงานเบา (ถ้าเรียก "แซน" แล้วพูดเรื่องอื่น จะบอกว่าทำอะไรได้บ้าง)
- 🌐 หน้าเว็บบนบอร์ดยังสั่งรถได้เหมือนเดิม (http://robot.local)

```
Chrome เต็มจอ (face.html)  ──localhost──>  Termux: brain.py  ──WiFi HTTP──>  ESP8266 ──> L298N ──> ล้อ
  หน้าตา / ฟัง / พูด / กล้อง                   สมอง (แปลงคำพูดเป็นคำสั่งรถ)
```

## โครงสร้าง

| ไฟล์ | ทำอะไร |
|---|---|
| `phone/brain.py` | สมอง: รับคำที่ได้ยิน → สั่งรถ, โหมดตามหน้า, เสียงพูด (Python ล้วน ไม่ต้อง pip) |
| `phone/commands.py` | แปลงคำพูดไทยเป็นคำสั่งรถ `F<ซม.> B<ซม.> L<องศา> R<องศา>` และเส้นทางรูปทรง |
| `phone/face.html` | หน้าตาแซนใน Chrome: วาดตา ฟังเสียง เล่นเสียงพูด กล้องจับหน้า |
| `phone/start.sh` | เปิดทุกอย่างด้วยคำสั่งเดียว |
| `phone/get_vendor.sh` | โหลด MediaPipe มาเก็บในเครื่อง |
| `firmware/robot_ai/` | เฟิร์มแวร์ NodeMCU: คุมมอเตอร์ WiFi และหน้าเว็บสั่งรถ |

## ติดตั้ง

### บอร์ด (NodeMCU 1.0 / ESP-12E)
1. คัดลอก `firmware/robot_ai/secrets.example.h` เป็น `secrets.h` แล้วใส่ชื่อ/รหัส WiFi (2.4 GHz เท่านั้น)
2. อัปโหลดด้วย Arduino IDE หรือ `arduino-cli upload -p <พอร์ต> --fqbn esp8266:esp8266:nodemcuv2 firmware/robot_ai`

### มือถือ (Termux)
```
pkg install python
bash phone/get_vendor.sh
bash phone/start.sh
```
แล้วแตะหน้าจอใน Chrome เพื่อปลุกแซน อนุญาตไมค์และกล้อง

## ข้อควรรู้
- การฟังเสียงของ Chrome และเสียงพูด (Google Translate TTS แบบไม่เป็นทางการ) ต้องใช้อินเทอร์เน็ต
- หน้าเว็บและ API ของบอร์ดไม่มีรหัสผ่าน ใครอยู่ใน WiFi เดียวกันสั่งรถได้ ใช้ในเครือข่ายที่ไว้ใจเท่านั้น
- `brain.py` รับคำสั่งควบคุมเฉพาะจากในมือถือเอง (localhost)
- แตะหน้าจอ = รถหยุดทันที
