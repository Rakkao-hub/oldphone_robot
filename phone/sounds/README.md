# เสียงอุทานของแซน

วางไฟล์เสียงที่นี่ ตั้งชื่อตามชื่อใน `EXCLAIMS` (ใน `commands.py`) แล้วกด Cmd+Shift+B ส่งขึ้นมือถือ

| ชื่อไฟล์ | เรียกด้วย | ถ้าไม่มีไฟล์ แซนพูดว่า |
|---|---|---|
| `wow.mp3` | อุทานว้าว / ทำเสียงโอ้โห | ว้าววว |
| `yay.mp3` | อุทานเย้ / ทำเสียงไชโย | เย้ เย้ |
| `oops.mp3` | อุทานอุ๊ย / ทำเสียงโอ๊ะ | อุ๊ย |
| `hmm.mp3` | อุทานหืม / ทำเสียงงง | หืมมม |
| `aww.mp3` | อุทานโธ่ / ทำเสียงเสียดาย | โธ่ เสียดายจัง |
| `haha.mp3` | หัวเราะ / อุทานฮา | ฮา ฮา ฮา |
| `ahhh.mp3` | อุทานอ่า / ทำเสียงอ้า | อ่า |
| `sing.mp3` | ร้องเพลง | ลา ลา ลา |

- ใช้ได้ทั้ง `.mp3` `.wav` `.ogg` `.m4a` ยาวไม่เกิน 20 วินาที
- พูดแค่ "อุทาน" = สุ่มเสียง
- ในสคริปต์แนะนำตัวใช้ `("!wow", "surprised", "")` ได้
